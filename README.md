# devops-portfolio

## Про мене

Привіт! Я Юрій — студент 4 курсу, що переходить з розробки на C# у бік DevOps. Маю досвід роботи з C# та інструментами для розробки RAG-систем на Python, зараз системно вивчаю інструменти адміністрування, автоматизації та контейнеризації. Цей репозиторій — портфоліо курсу DevOps: тут накопичуються звіти й код усіх лабораторних робіт та фінального проєкту.

## Професійна мета

Стати **DevOps-інженером**: будувати надійні, автоматизовані та відтворювані процеси доставки й експлуатації програмного забезпечення — від Git-workflow і CI/CD до контейнеризації та інфраструктури як коду.

## Технології

### Вже знаю
- C# / .NET

- Git / GitHub (professional workflow, branch protection)

- Node.js (через менеджер версій nvm)

### Планую вивчити
- CI/CD (GitHub Actions)
- Kubernetes
- Terraform / Infrastructure as Code

- Хмарні платформи (AWS/Azure)

## План розвитку на рік

1. **Семестр 1 (поточний курс)** — освоїти базові DevOps-практики: Git workflow, контейнеризація, CI/CD пайплайни, основи інфраструктури як коду.
2. **Наступні 3–6 місяців** — поглибити знання Kubernetes і Terraform, отримати практичний досвід на pet-проєктах.
3. **До кінця року** — зібрати портфоліо реальних проєктів (включно з фінальним проєктом курсу), спробувати профільне стажування/першу позицію Junior DevOps.
